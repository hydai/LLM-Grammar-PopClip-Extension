# LLM Grammar Check

Send the selected text to an OpenAI compatible LLM service, such as [OpenAI](https://platform.openai.com/docs/overview), for grammar and spell checking.

### Configuration

#### API Endpoint

* **OpenAI:** defaults to `https://api.openai.com/v1`
* **Other OpenAI compatible services:** use the base URL of the service

#### API Key

* **OpenAI:** https://platform.openai.com/account/api-keys
* **Other OpenAI compatible services:** use the key issued by the service, or leave this empty if none is required

#### Model Name

* **OpenAI:** default model is `gpt-6-luna`
* **Other OpenAI compatible services:** use a model name available on the service

## About

This is an extension for [PopClip](https://pilotmoon.com/popclip/).
